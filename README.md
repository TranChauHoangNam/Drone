# Drone

Mã nguồn và tài liệu cho dự án drone tìm kiếm cứu nạn, gồm công cụ nhận diện,
huấn luyện, bộ starter kit, các bài kiểm thử và hướng dẫn vận hành.

## Thư mục chính

- `drone_yolo_detect.py`, `train_sar_drone.py`: nhận diện và huấn luyện YOLO.
- `student-starter-kit/`: starter kit và tài liệu hướng dẫn.
- `student-starter-kit-v2/student-starter-kit/`: phiên bản starter kit v2.
- `start_camera_bridge.sh`: khởi chạy camera bridge.

Các checkpoint, dataset, thông tin đăng nhập, kết quả sinh tự động và gói nộp
không được đưa vào repository. Cần cung cấp model weights riêng trước khi chạy
pipeline YOLO.
